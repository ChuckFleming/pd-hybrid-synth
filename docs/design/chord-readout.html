A larger chord readout under the Chord card

Column 3 of the VOICE page has 96 px × 415 px free below Chord — measured, not estimated. Three ways to use it, all shown at exact size on the real panel surface, each with its Phosphor Mk II counterpart so you can see it works in both skins.

All three are fed by ChordNamer, which already exists and already produces every string shown here — the name, the inversion slash, and the note spellings.

Notes

  • All three fit the measured slot exactly — 76 px of display inside a 96 px space, leaving the 10 px card gap. None of them push anything else down or touch the footer.
  • No new DSP is needed. ChordNamer::name() already returns every string here including Am7/G, C4 and C-G P5, and the processor already publishes the sounding notes. This is display work only.
  • A is the biggest name, C is the most informative. B is the only one that explains why a chord is sounding, which matters in chord mode where one key produces four notes — but it is the only one that goes half-blank when chord mode is off.
  • The idle state is the one to decide deliberately. Shown here as a dim dash rather than an empty box: a readout that empties and refills pulls the eye on every note-off, which is distracting on a page you are editing.
  • Placed under Chord it reads as part of chord mode, but it is fed from everything sounding — so it names what you play with chord mode off too. If that is confusing, it could carry a plain SOUNDING caption rather than sitting inside the Chord card, which is how it is drawn here.
