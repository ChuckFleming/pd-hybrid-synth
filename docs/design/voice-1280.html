What changed, and why it fits

  • Column packing is what buys the fit. The old grid padded every card in a row to the tallest card in it — Mixer was half empty because Mono Bass sat beside it. Here each card is only as tall as its own contents, and cards fall into whichever column is shortest. That alone recovers roughly 300 px.
  • The knobs only had to come down from 64 px to 48 px. Tightening alone would have needed ~36 px knobs and still not fit. Because the reflow does the structural work, the controls stay comfortably clickable.
  • Osc A and Osc B keep all ten knobs — at three columns each card is ~415 px wide, which takes seven cells per row, so they wrap to two rows rather than needing a third column.
  • The Inspector is a drawer (the Inspector ▸ tab at the right of the tab bar). Reclaiming its permanent 236 px is what lets three columns be wide enough to be useful.
  • The chord readout fills the space under Chord — 76 px of the 96 px that column had free, leaving 14 px of clearance. The marquee name at 29 px, the sounding notes, and a strip lighting the pitch classes. It is fed by ChordNamer, which already returns every string shown, so this is display work only.
  • It names whatever is sounding, not only chord-mode output — play a triad by hand with chord mode off and it still reads Dm7. Sitting under Chord implies otherwise; if that reads wrong it should become its own card captioned SOUNDING.
  • Nothing was removed. Every control from the current VOICE page is present — this is the same page, packed.
  • The performance strip drops 150 → 110 px by shrinking the envelope display and using the smaller knob size for the ADSR row; the spectrum stretches to fill whatever width is left.
